# Data Broker Audit

From Ai Brain Notes resource. Free pattern; manual submit only. Never buy reports, never investigate relatives, never auto-submit.

## Instructions

### Step 1: Audit (prompt)
Help me audit my own information on people-search and data-broker sites and prepare a removal plan. Start by asking my country, name and relevant cities. Search only for profiles about me using details I approve. Show each profile link, why you think it matches, and the types of information actually visible. Separate uncertain matches and inaccessible sites. Do not buy reports, investigate relatives or submit anything.

User confirms which profiles are theirs (same-name risk). Keep uncertain separate.

### Step 2: Opt-out plan (same chat, prompt)
For the profiles I confirm are mine, find each site's current official opt-out instructions. Use the site's own pages and link directly to them. Mark anything you cannot verify. Draft the request or proposed form entries using only information I've supplied or approved. Ask for any missing required information. Show me the exact destination and what I would disclose. Do not send or submit anything yet.

### Step 3: Browser submit (per site, explicit approval)
Open the official removal page for the first confirmed profile. Show me the fields and exact request before entering private details or submitting. After I explicitly approve that destination, request and disclosure, enter the approved details and submit it. Ask again if anything material changes. Let me handle identity checks, CAPTCHA and email confirmation links. Keep submitted, awaiting confirmation and removal verified as separate statuses.

### Step 4: Track + monthly recheck
Tracker table: site | profile link | match reason | visible fields | status (submitted/awaiting/verified) | date. Scheduled monthly recheck on the 1st, approval-gated for new removals.
