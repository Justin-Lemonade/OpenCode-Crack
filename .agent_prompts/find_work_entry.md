__Run the Find-Work Protocol__

Open `.agent_prompts/find_work.md`, read it in full, and make sure you
completely understand the protocol before doing anything else — it is
your sole source of instructions. Then execute it top to bottom,
following every step exactly as written. Loop back to step 1 when you
reach the end unless you were told to do a fixed number of tasks or
to stop.

If you notice a problem with the project itself along the way, file it —
see `.agent_prompts/raise_concern.md`.

Do not ask what to work on — that's what the file is for. Only stop and ask a human if you hit a STOP CONDITION.
